## Typographies

- **Titres (H1–H4) :** Cormorant Garamond — Google Fonts
- **Corps / navigation / boutons :** Nunito — Google Fonts

Dans Kadence : Apparence → Personnaliser → Typographie → charger les deux polices via Google Fonts.

## Installation du favicon dans WordPress

1. Convertir `favicon.svg` en PNG 512×512 avec un outil en ligne (ex: svgtopng.com)
2. Dans WordPress : Apparence → Personnaliser → Identité du site → Icône du site
3. Uploader le PNG 512×512
4. WordPress génère automatiquement toutes les tailles (32×32, 192×192, etc.)

## Installation du logo dans WordPress

1. Dans WordPress : Apparence → Personnaliser → Identité du site → Logo
2. Uploader `logo.svg` directement (Kadence supporte les SVG)
3. Ou convertir en PNG 800×200 si problème d'affichage
4. Hauteur recommandée dans Kadence Header : 60px
